# dsh-session-prompt-vault（提示词仓库）

在输入框工具栏左侧新增一个 ⚡ 按钮，点开弹窗集中管理常用提示词，一键插入输入框，并支持 WebDAV 基础同步。

## 安装

- GitHub 仓库：`git@github.com:lwfjyjy/dsh-session-prompt-vault.git`
- 在 DSH 插件管理器中添加该仓库（或本地安装本目录）即可。

## 功能

- **左下角按钮**：位于输入框工具行的左侧（"+" 号所在区域）；悬停/聚焦时显示用途提示和当前快捷键。
- **弹窗管理提示词**：支持新增、修改、删除、搜索。
- **拼音搜索**：搜索框支持中文原文、整串拼音（如 `daima`）和拼音首字母（如 `dmsc`）；`ü` 可写作 `v` 或 `u`。拼音表离线内置，运行时不依赖第三方库。
- **分组**：可为提示词设置分组；列表上方按分组筛选（含「全部 / 未分组」），分组名支持输入时自动补全。
- **一键插入**：点击某条提示词即可插入到输入框光标处；也可用 `↑ / ↓` 选择、`Enter / Tab` 插入、`Esc` 关闭。
- **设置弹窗（两个 tab）**：
  - **快捷键**：点击键位按钮后按下新组合键即可录制；右侧 × 可删除快捷键（删除前会确认），也支持「恢复默认」；默认 `⌘⇧I` / `Ctrl+Shift+I`，用它可随时打开弹窗。
  - **同步设置**：即下面的 WebDAV 同步配置。
- **WebDAV 同步（基础）**：
  - 填写 WebDAV 地址、用户名、密码；
  - **立即同步**：确认后把本地提示词推送到云端；
  - **从服务器恢复**：确认后用云端提示词覆盖本地，成功后自动回到列表；
  - **自动同步**：可选 关闭 / 3 / 15 / 30 分钟 / 1 小时；开启后修改提示词会自动上传，并按所选间隔定时备份。
  - 云端文件位置：`<地址>/dsh-session-prompt-vault/prompts.json`。
  - **地址从哪来**：坚果云在「设置 → 常规设置 → 第三方应用管理 → 管理」里添加应用，即可获得 WebDAV 地址和应用密码（用户名填坚果云账号，密码填生成的应用密码；地址一般形如 `https://dav.jianguoyun.com/dav/`）；其他网盘在各自的设置/安全中开通。
  - 同一台电脑上的自动/手动同步会排队串行执行，不会并发覆盖；若正在恢复云端数据，会跳过之前排队的自动上传。多台电脑同时编辑仍是「后写覆盖先写」，换设备建议先点“从服务器恢复”再编辑。手动上传/恢复都会先弹出应用内确认；后台自动同步不会打断操作，因此不弹确认。

## 说明

- **升级兼容**：从旧插件名 `dsh-session-quick-prompt` 升级时，会第一次读取时自动迁移本机 localStorage 中的提示词、设置和快捷键；云端读取也会兼容旧目录，不会丢数据。
- 提示词与同步设置（含 WebDAV 密码）都保存在本机浏览器 `localStorage`，不会上传到除你配置的 WebDAV 之外的地方。
- WebDAV 的网络请求由 DSH 宿主（Node 进程）代理转发（`POST /dsh-session-prompt-vault/webdav`），以避开浏览器跨域限制；密码只在单次请求中由宿主透传，不写入宿主配置、不落宿主日志。
- 样式全部使用 DSH 设计令牌（`--dsw-*`），自动适配浅色 / 深色主题与 Windows / macOS。

## 开发

- 宿主入口：`index.js`（WebDAV 请求代理）。
- 客户端入口：`client.js`（React 组件，注册到 `conversation.input.left` 插槽）。
- 清单：`package.json`、`cordis.patch.yml`、`locale/{zh,en}.json`、`icon.svg`。

### 代码结构（便于维护 / 扩展）

- `client.js` 自上而下分层：类型与常量 → 文案 → 图标 → 通用工具 → 本地存储 → 云端客户端 → 纯选择器（分组 / 搜索）→ 输入框操作 → 复用 Hooks（持久化 / 自动同步 / 快捷键）→ 基础组件 → 子视图（列表 / 编辑 / 设置 / 外壳）→ 主组件 → 样式 → 拼音字典（数据）→ 装配。
- 拼音字典由 pinyin-pro 3.29.5（MIT）离线生成并内置，只作为静态数据，不引入运行时依赖。
- 主组件用单一 `screen` 状态描述当前层级（`null` / `list` / `settings` / `edit`），关闭时逐层返回。
- `index.js` 分层：常量 → HTTP 工具 → WebDAV 客户端（`readRemote` / `writeRemote`）→ 路由处理器 → `apply` 装配。
- 新增一种云端后端时，只需改宿主侧 `readRemote` / `writeRemote`，客户端无需改动。
